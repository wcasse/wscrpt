# wscrpt 0.2.2

**Suggested GitHub release title:** `wscrpt 0.2.2`

---

## Stickies pad + Agents dashboard on the remote-first core

**wscrpt** is a remote-first terminal IDE for real development hosts — especially **iPad + Magic Keyboard** sessions over **Blink**, **SSH**, or **mosh** (often with tmux).

0.2.2 keeps the deliberate 0.2 core and the 0.2.1 daily workflow surface, then ships the two surfaces that make the product feel alive on a thin client: a **floating Stickies notepad** and a single bottom **Agents dashboard** (safe fake agent by default, host-auth readiness, no secrets in config).

- **Repo:** https://github.com/wcasse/wscrpt
- **Tag:** `v0.2.2`
- **License:** MIT
- **MSRV:** Rust **1.88+** (Unix-like hosts: macOS / Linux; WSL 2 is the Windows route)

---

## Install

Rust **1.88** or newer. Interactive stdin/stdout required for the editor (probes below are non-interactive).

**Recommended (from GitHub tag):**

```sh
cargo install --git https://github.com/wcasse/wscrpt --tag v0.2.2 --locked
wscrpt --health
```

**From crates.io** (after publish):

```sh
cargo install wscrpt --locked
wscrpt --health
```

**From a local checkout:**

```sh
git clone https://github.com/wcasse/wscrpt.git
cd wscrpt
git checkout v0.2.2
cargo install --path . --locked
wscrpt --health
```

Non-interactive probes: `wscrpt --version`, `wscrpt --health`, `wscrpt --print-default-config`, `wscrpt --print-command-reference`.

## Highlights

### Floating Stickies notepad

Mac Stickies–style jotting without a second IDE:

- `Esc w k` / `:stickies` — toggle the top-right pad
- `Esc w K` / `:new-sticky` — new personal note (file- or workspace-anchored)
- In-pad focus, note cycle, save / archive / delete chords
- Markdown + TOML front matter under the hood; personal notes in XDG state; team notes under `.wscrpt/stickies/`
- Pad geometry stays off the workspace git tree
- If the pad is open when you start an agent run, the active note is attached as a bounded sticky brief on the work packet

### Agents dashboard (single surface)

- `Esc w a` / `:agent` — start a goal (plan-first **fake** loop by default)
- `Esc w x` — cancel
- `Esc w D` / `:agent-dashboard` — toggle bottom roster + full receipt
- `wscrpt --health` reports agent mode and host-auth readiness markers (no secrets stored)
- Configure a real host CLI when ready (`agent.use_fake = false`, `agent.argv = …`); see [AGENT_AUTH.md](https://github.com/wcasse/wscrpt/blob/v0.2.2/docs/AGENT_AUTH.md)
- **Not in this release as a claim:** autonomous merge/push, provider marketplace, or “ACP is live out of the box”

### Still in 0.2.1 (unchanged core)

First-run help, LSP footer / PATH discovery snippets, trusted local Git stage/unstage/commit-staged, first-edit cue after Action mode, `Esc l` / `Esc L` line actions, tmux OSC 52 passthrough, remote paint polish.

## Blink + mosh (quick)

On the **host** (once):

```sh
cargo install --git https://github.com/wcasse/wscrpt --tag v0.2.2 --locked
```

On the **iPad**: Blink → `mosh user@host` (or `ssh`) → optional tmux → `wscrpt .`  
If keys feel wrong: `wscrpt --input-diagnostics` and the iPad matrix doc.
