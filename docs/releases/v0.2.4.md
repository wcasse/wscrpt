# wscrpt 0.2.4

**Suggested GitHub release title:** `wscrpt 0.2.4`

---

## ACP process + pad reliability

**wscrpt** is a remote-first terminal IDE for real development hosts — especially **iPad + Magic Keyboard** sessions over **Blink**, **SSH**, or **mosh** (often with tmux).

0.2.4 is the install pin that adds a real **ACP stdio process path** (opt-in; fake remains default) plus checklist apply / pad scroll hardening since 0.2.3.

- **Repo:** https://github.com/wcasse/wscrpt
- **Tag:** `v0.2.4`
- **License:** MIT
- **MSRV:** Rust **1.88+** (macOS / Linux; WSL 2 for Windows)

---

## Install

```sh
cargo install --git https://github.com/wcasse/wscrpt --tag v0.2.4 --locked
wscrpt --health
```

---

## Highlights since 0.2.3

| Surface | Notes |
| --- | --- |
| ACP process | `agent.use_fake = false` + `argv = ["grok", "agent", "stdio"]` after host login |
| Checklist apply | Re-resolve task text at `Esc w Y` (survives mid-run body edits) |
| Pad scroll | Viewport tracks painted card height |

### Agents honesty

Default remains **`agent.use_fake = true`**. Real ACP is opt-in config + host auth (`docs/AGENT_AUTH.md`). Permission prompts are cancelled (not silently approved). Full fs/terminal mediation and Needs You UX remain follow-ups.
