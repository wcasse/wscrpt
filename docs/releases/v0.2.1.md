# wscrpt 0.2.1

**Suggested GitHub release title:** `wscrpt 0.2.1`

---

## Remote polish for the 0.2 core

**wscrpt** is a remote-first terminal IDE for real development hosts — especially **iPad + Magic Keyboard** sessions over **Blink**, **SSH**, or **mosh** (often with tmux).

0.2.1 is a quality release on the 0.2 core: first-run help, daily LSP visibility, measured renderer paint reductions for remote links, a real tmux clipboard route, and a mouse hit-testing fix. No commands were added or removed.

- **Repo:** https://github.com/wcasse/wscrpt
- **Tag:** `v0.2.1`
- **License:** MIT
- **MSRV:** Rust **1.88+** (Unix-like hosts: macOS / Linux)

---

## Install

Rust **1.88** or newer. Interactive stdin/stdout required for the editor (probes below are non-interactive).

**Recommended (from GitHub tag):**

```sh
cargo install --git https://github.com/wcasse/wscrpt --tag v0.2.1 --locked
wscrpt --health
```

**From a local checkout:**

```sh
git clone https://github.com/wcasse/wscrpt.git
cd wscrpt
git checkout v0.2.1
cargo install --path . --locked
wscrpt --health
```

Non-interactive probes: `wscrpt --version`, `wscrpt --health`, `wscrpt --print-default-config`, `wscrpt --print-command-reference`.

## Highlights

### First-run help and daily LSP visibility

- A one-time help overlay on first launch (state kept in the XDG state directory, never in the workspace; `WSCRPT_SKIP_FIRST_RUN_HELP=1` for automation).
- The footer shows the attached language server and its state; when a server is discovered on PATH but not authorized, errors name it and give the exact config step.
- `wscrpt --print-default-config` now emits ready-to-uncomment `[[language_servers]]` blocks for servers found on PATH.
- Optional `format_on_save` (default off).

### tmux clipboard, done properly

Copies inside tmux now wrap OSC 52 in tmux's **DCS passthrough envelope**, so the sequence reaches the outer terminal (Blink) directly instead of depending on tmux's `set-clipboard` forwarding.

> **Upgrade note:** on tmux **3.3+**, add `set -g allow-passthrough on` to your tmux config. `wscrpt --health` inside tmux reminds you; the Workspace Info route snapshot shows the selected transport.

### Faster frames over SSH/mosh

Validated renderer optimizations: differential style emission per span and allocation-free grapheme display. Measured on the project harness: roughly **9–12% fewer output bytes per frame** for typing and scrolling — bytes on the wire are the metric that matters on a laggy link.

### Fixes

- Mouse clicks with the project sidebar visible landed sidebar-width cells left of the pointer (and wrapped scrolling used the wrong width). Hit-testing now mirrors the renderer's layout; clicks inside the sidebar are ignored. Mouse reporting remains **off by default**.
- Buffer tabs keep a fixed position-indexed color scale, so switching buffers never recolors the header.
- `scripts/verify.sh` derives the package version from Cargo metadata instead of a hardcoded string.

See [CHANGELOG.md](https://github.com/wcasse/wscrpt/blob/v0.2.1/CHANGELOG.md) for details, and the 0.2.0 notes for the deliberate scope of the 0.2 core.

## Blink + mosh (quick)

On the **host** (once):

```sh
cargo install --git https://github.com/wcasse/wscrpt --tag v0.2.1 --locked
```

On the **iPad**: Blink → `mosh user@host` (or `ssh`) → optional tmux → `wscrpt .`
If keys feel wrong: `wscrpt --input-diagnostics` and work through the iPad matrix doc.
