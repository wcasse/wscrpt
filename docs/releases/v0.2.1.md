# wscrpt 0.2.1

**Suggested GitHub release title:** `wscrpt 0.2.1`

---

## Remote-first core, with daily workflow surface

**wscrpt** is a remote-first terminal IDE for Mac and Linux — especially **iPad + Magic Keyboard** sessions over **Blink**, **SSH**, or **mosh** (often with tmux).

0.2.1 keeps the deliberate 0.2 core and adds the day-to-day surfaces that make it recommendable: first-run help, clearer LSP status, Stickies, a tiny trusted Git mutation slice, an unmistakable first-edit cue after Action mode, host-support clarity, and measured remote-frame polish. Agent-native work is contracts-only (W0); no autonomous agent UI yet.

- **Repo:** https://github.com/wcasse/wscrpt
- **Tag:** `v0.2.1`
- **License:** MIT
- **MSRV:** Rust **1.88+** (Unix-like hosts: macOS / Linux; WSL 2 is the Windows route)

---

## Install

Rust **1.88** or newer. Interactive stdin/stdout required for the editor (probes below are non-interactive).

**Recommended (from GitHub tag):**

```sh
cargo install --git https://github.com/wcasse/wscrpt --tag v0.2.1 --locked
wscrpt --health
```

**From crates.io** (after publish):

```sh
cargo install wscrpt --locked
wscrpt --health
```

**From a local checkout:**

```sh
git clone https://github.com/wcasse/wscrpt.git
cd wscrpt
git checkout v0.2.1
cargo install --path . --locked
wscrpt --health
```

Non-interactive probes: `wscrpt --version`, `wscrpt --health`, `wscrpt --print-default-config`, `wscrpt --print-command-reference`.

## Highlights

### Stickies

Personal and team Markdown notes with a small TOML front-matter block.

- `Esc w k` / `:stickies` — list (filter, Enter opens, `A` archives)
- `Esc w K` / `:new-sticky` — create a personal sticky anchored to the current file (or workspace)
- Personal storage under XDG state; team notes under `.wscrpt/stickies/` (layout never enters the workspace)

### Trusted local Git mutations (small surface)

Back by design, deliberately narrower than a full Git client:

| Action | Route |
| --- | --- |
| Stage current saved file | `Esc v S` / `:stage-current` |
| Unstage current file | `Esc v U` / `:unstage-current` |
| Commit staged | `Esc v c` / `:commit-staged` |

Trust is required every run (hooks/filters may execute). Branch, network, discard/reset/clean, and signed commits stay in the workspace shell (`Esc t t`).

### First-edit cue

After leaving the Action layer, only the **first successful document edit** shows a short steady `EDIT*` / cursor acknowledgement. Navigation and rejected edits do not consume it.

### Line actions

- `Esc l` — select current line / expand selection to whole lines
- `Esc L` — toggle line numbers

### First-run help and daily LSP visibility

- One-time help overlay on first launch (XDG state only; `WSCRPT_SKIP_FIRST_RUN_HELP=1` for automation).
- Footer shows attached language server state; unauthorized discoveries name the binary and the config step.
- `wscrpt --print-default-config` emits ready-to-uncomment `[[language_servers]]` blocks for PATH discoveries.
- Optional `format_on_save` (default off).

### tmux clipboard, done properly

Copies inside tmux wrap OSC 52 in tmux's **DCS passthrough envelope**, so the sequence reaches Blink directly.

> **Upgrade note:** on tmux **3.3+**, add `set -g allow-passthrough on`. `wscrpt --health` inside tmux reminds you.

### Faster frames over SSH/mosh

Differential style emission and allocation-free grapheme display — fewer output bytes per frame on laggy links.

### Host support

macOS and Linux are the tested remote hosts. WSL 2 is the practical Windows path. Native Windows is not claimed. See [HOST_SUPPORT.md](https://github.com/wcasse/wscrpt/blob/v0.2.1/docs/HOST_SUPPORT.md).

### Agent-native (W0 only)

Contracts and a host-local admission coordinator are in-tree and unit-tested. No ACP process, activity drawer, or filesystem mutation from agents in this release.

### Optional native preview harness

`clients/ipad-preview-harness` and `previewd/` ship for contributors working on the combined terminal/player experiment. They are **not** part of `cargo install wscrpt` and are excluded from the crates.io package.

### Fixes

- Sidebar mouse hit-testing matches the rendered layout; clicks in the sidebar are ignored. Mouse reporting remains **off by default**.
- Buffer tabs keep a fixed position-indexed color scale.
- `scripts/verify.sh` derives the package version from Cargo metadata.

See [CHANGELOG.md](https://github.com/wcasse/wscrpt/blob/v0.2.1/CHANGELOG.md) for the full list, and the 0.2.0 notes for the deliberate scope of the 0.2 core.
