# wscrpt 0.2.0

**Suggested GitHub release title:** `wscrpt 0.2.0`

---

## Remote-first terminal IDE core

**wscrpt** is a remote-first terminal IDE for Mac and Linux — especially **iPad + Magic Keyboard** sessions over **Blink**, **SSH**, or **mosh** (often with tmux).

Ordinary typing stays ordinary. `Esc` (or `Ctrl-K`) opens a **no-timeout** action layer that does not depend on Command-key chords or permanent panel clutter. Mouse reporting is **off by default** so Blink can keep native touch selection.

Version **0.2** is a deliberate core: editing, workspace navigation/search, trusted tasks, recovery, sessions, read-only Git, bounded LSP, and a safe full-screen workspace shell. It is **not** a VS Code clone.

- **Repo:** https://github.com/wcasse/wscrpt
- **Tag:** `v0.2.0`
- **License:** MIT
- **MSRV:** Rust **1.88+** (Unix-like hosts: macOS / Linux)

## Install

Rust **1.88** or newer. Interactive stdin/stdout required for the editor (probes below are non-interactive).

**Recommended (from GitHub tag):**

```sh
cargo install --git https://github.com/wcasse/wscrpt --tag v0.2.0 --locked
wscrpt --health
```

**From a local checkout:**

```sh
git clone https://github.com/wcasse/wscrpt.git
cd wscrpt
git checkout v0.2.0
cargo install --path . --locked
wscrpt --health
```

Non-interactive probes: `wscrpt --version`, `wscrpt --health`, `wscrpt --print-default-config`, `wscrpt --print-command-reference`.

## Highlights (0.2 core)

### Editing and workspace

- UTF-8 / grapheme-aware editing, soft wrap, selections, undo/redo, find/replace, syntax highlight, LF/CRLF, atomic saves, external-change detection
- Multi-buffer workspace: Quick Open, tree/sidebar, recent/dirty/closed files, create/rename/copy, project search, outlines, bookmarks, jump history

### Tasks, LSP, Git (bounded on purpose)

- **Tasks:** `.wscrpt/tasks.toml` argument vectors, **trust before every run**, bounded output, process-group cancel, Problems extraction
- **LSP:** user-global servers only (never enabled merely by opening a project); diagnostics, completion, hover, definition, references, symbols, single-document format
- **Git:** **read-only** inspect (status, diff, log, blame, branches, …). Mutating Git stays in the workspace shell

### Resilience and remote UX

- Session restore, recovery journals, bracketed paste, differential redraw, terminal restore on exit/panic
- No-timeout action prefixes; Escape reliability prioritized for laggy remote paths
- Full-screen workspace shell (`Esc t t` / `:terminal`); exit returns to the editor
- Startup indexing, Git status, and recovery scanning run after the first frame on bounded background workers (stale results rejected)

### Intentional non-goals (0.2)

These were removed or never shipped as product surface — use shell or trusted external tools instead:

| Area | Not in 0.2 | Use instead |
| --- | --- | --- |
| Embedded / split / panel terminals | `Esc t T` / `t v` / `t p` and related | Full-screen shell: `Esc t t` or `:terminal` |
| Project-wide replace | `Esc w p` | Trusted task or shell tool; in-buffer: `Esc R` |
| LSP rename / code actions | `Esc c n` / `Esc c a` | Local edit or trusted external refactor |
| In-editor Git stage/commit/push/pull/checkout | former `Esc v S/U/c/k/p/P` routes | Workspace shell (`git add`, `commit`, `switch`, …) |

Also not goals: local GUI IDE workflows, Windows-first hosts, full LSP multi-file rewrite suites.

See [CHANGELOG.md](https://github.com/wcasse/wscrpt/blob/v0.2.0/CHANGELOG.md) for the full removed-command table and migration notes (including session format v2).

## Blink + mosh (quick)

On the **host** (once):

```sh
cargo install --git https://github.com/wcasse/wscrpt --tag v0.2.0 --locked
```

On the **iPad**: Blink → `mosh user@host` (or `ssh`) → optional tmux → `wscrpt .`  
If keys feel wrong: `wscrpt --input-diagnostics` and work through the iPad matrix doc.
