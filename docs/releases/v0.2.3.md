# wscrpt 0.2.3

**Suggested GitHub release title:** `wscrpt 0.2.3`

---

## Pad paste fix + checklist + receipt write-back

**wscrpt** is a remote-first terminal IDE for real development hosts — especially **iPad + Magic Keyboard** sessions over **Blink**, **SSH**, or **mosh** (often with tmux).

0.2.3 is the install pin that matches current day-to-day Stickies + Agents product on `main` after the 0.2.2 core cut: checklist fan-out, human-confirmed receipt log append, sticky-focused paste, and ship-surface regression tests.

- **Repo:** https://github.com/wcasse/wscrpt
- **Tag:** `v0.2.3`
- **License:** MIT
- **MSRV:** Rust **1.88+** (macOS / Linux; WSL 2 for Windows)

---

## Install

```sh
cargo install --git https://github.com/wcasse/wscrpt --tag v0.2.3 --locked
wscrpt --health
```

From crates.io (after publish):

```sh
cargo install wscrpt --locked
```

## Highlights since 0.2.2

| Surface | Keys |
| --- | --- |
| Sticky pad | `Esc w k` / `Esc w K` |
| Checklist fan-out / apply | `Esc w C` / `Esc w Y` |
| Receipt log append (after Review) | `Esc w A` |
| Agent run / cancel / dashboard | `Esc w a` / `Esc w x` / `Esc w D` |

### Fixed

- Paste while the sticky pad is focused updates the **note**, not the document.

### Agents honesty

Default remains **`agent.use_fake = true`**. Real host CLI / ACP is opt-in configuration, not “autonomous ship.”

### Still in 0.2.x core

First-run help, LSP footer/PATH discovery, trusted Git stage/unstage/commit-staged, first-edit cue, `Esc l`/`Esc L`, tmux OSC 52 passthrough, remote paint polish.
