01 · Identity

Canonical name is wscrpt — lowercase, no periods, matching the crate, binary, and GitHub repo.

Use

  • wscrpt everywhere public
  • Pair with short category line when search/SEO needs help
  • Primary tagline under the name on hero surfaces

Avoid

  • W.SCRPT / Wscrpt as primary brand
  • w.scrpt in install copy or logos
  • AI-mascot, gradient “play” triangles, VS Code-clone chrome

02 · Voice

Developer-tool honest. Concrete remote/Blink facts over marketing fog. Deliberate small core — not “full IDE.”

Do

  • “Action layer never times out”
  • “Mouse off by default for Blink”
  • “Trust-gated tasks / user-global LSP only”
  • Install in two lines; admit confidence gates

Don’t

  • “Supercharge / 10x / AI-native platform”
  • “Delightful mobile experience”
  • Fake social proof or fake audits
  • Autonomous agent / ACP out-of-the-box hype

08 · Usage rules

Clear space & backgrounds

  • Prefer mark on #0B0B0C or pure black
  • Keep indigo chevron readable at 16–32px
  • OG always includes wordmark + primary tagline + repo URL

Do not

  • Swap primary accent back to default terminal cyan for brand
  • Add drop shadows / glassmorphism / neon glow spam
  • Stretch the mark or set type in a second decorative font
  • Lead with agent/preview chrome the pin does not ship
